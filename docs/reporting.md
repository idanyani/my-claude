# Report to steer

Terms in *italics* are defined in [the index](README.md).

The developer steers the fleet from what its agents report, often after days away. Because *work
outruns attention*, a report spends the scarcest resource the central principle counts, and an
agent with a *misjudged own state* overstates what it checked. So every report is short, shows how
well each claim is backed and which choices the agent made alone, and asks only the few decisions
that are the developer's.

## In my-claude

- The [brief](../dot-claude/skills/brief/SKILL.md) skill sets the format of reports and of
  questions that need background, and the "Messages to the user" conventions in
  [CLAUDE.md](../dot-claude/CLAUDE.md) say when it applies.
- A PR records a review's warnings about failures no run has shown as known limits, rather than
  offering them as work
  ([resolve-issue's workflow](../dot-claude/skills/resolve-issue/references/git-workflow.md)).
